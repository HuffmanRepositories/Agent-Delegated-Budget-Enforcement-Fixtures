# Governance

This repository is a small, community-reviewable fixture corpus. Maintainers may merge synthetic test cases and documentation improvements.

- Scope changes should preserve implementation neutrality.
- Fixture semantics should be discussed in issues or pull requests.
- Reviewers should flag ambiguity in units, scope, windows, and reservation state.
- No fixture is an official standard, certification test, or proof of runtime correctness.
- Contributions must not add real customer data, secrets, or unverified claims.

The maintainers may revise or remove fixtures when semantics are unclear or redundant.
