# Taxonomy

| Category | Meaning |
|---|---|
| concurrent-reservation | Competing child allocations against shared capacity |
| nested-allocation | Delegation within an already allocated child budget |
| reservation-settlement | Reserved amount reconciled to actual usage |
| release-refund | Unused reservation or refund lifecycle |
| revocation-exhaustion | Child authority after budget exhaustion or grant revocation |
| accounting-race | Lost/double updates to aggregate budget state |
| unit-scope | Mixed units or scope confusion |
| roll-up | Parent aggregation of child usage |
| lifecycle | Cancellation, timeout, late completion |
| window-boundary | Reset or budget-window transitions |
